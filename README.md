# Human Rights Awareness Website

A multi-page, responsive website raising awareness about human rights, with a focus on women's rights. It explains what human rights are, shares real-life stories with practical solutions, and lists organizations and professionals who can help people in difficult situations.

> Final project – HTML & CSS

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Introduction to human rights, women's rights, the issues we must fight, and a call to seek help |
| Stories | `public/pages/histoires.html` | Real-life experiences and solutions (education, budget management, personal safety, equal pay) |
| Support | `public/pages/assistance.html` | Women's support associations, psychologists and mental health, institutions, and a contact form |

## Built With

- HTML5
- CSS3
- [Tailwind CSS v4](https://tailwindcss.com/) (via `@tailwindcss/cli`)
- Custom CSS (`input.css`, `stayl.css`)

## Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd final-project-html-css
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Build the CSS** (Tailwind)
   ```bash
   npx @tailwindcss/cli -i ./public/css/input.css -o ./public/css/output.css --watch
   ```

4. **Open the site**
   Open `index.html` in your browser (or use the VS Code *Live Server* extension).
